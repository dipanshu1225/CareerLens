# 🤖 CareerLens 

### AI-Powered Resume & Career Intelligence Platform

CareerLens AI is an interactive AI-powered career platform built with **Python and Streamlit** that helps users analyze their resumes, match their skills with target job roles, identify skill gaps, and get career guidance through an AI assistant.

The goal of CareerLens AI is to provide users with a simple platform to understand their current career profile and identify what they need to improve for their target role.

## ✨ Features

### 📄 Resume Analyzer

Upload your resume in PDF format and get an instant analysis.

**Features include:**

- 📊 Resume score
- 🧠 Automatic skill detection
- 💼 Experience detection
- 📈 Resume evaluation
- 🔍 Resume insights
- ⚠️ Areas for improvement
- 📄 Extracted resume text

---

### 🎯 Job Matcher

Compare your resume against a target job role and understand how well your skills match.

**Features include:**

- 📄 Resume upload
- 💼 Multiple target job roles
- 📝 Job description input
- 🎯 Resume-job match score
- ✅ Matched skills
- ❌ Missing skills
- 📊 Visual match progress
- 🧠 Detected resume skills

Supported roles include:

- Data Analyst
- Data Scientist
- Machine Learning Engineer
- Python Developer
- AI/ML Engineer
- Business Analyst
- Software Developer

---

### 📊 Skill Gap Analyzer

Identify the skills you need to develop for your target career role.

**Features include:**

- 🎯 Target role selection
- 🧠 Current skill identification
- ❌ Missing skill detection
- 📈 Skill gap analysis
- 🚀 Learning recommendations

---

### 🤖 CareerLens AI Assistant

An interactive AI career assistant available directly from the home page.

The assistant can help users with:

- Resume improvement
- Career guidance
- Job requirements
- Skill recommendations
- Interview preparation
- Career planning
- Job-related questions
